# ZEROONE CANVAS｜動くバスケ作戦キャンバス v42

「問いから、プレーをつくる。」をコンセプトに、バスケットボールの作戦を作成・保存・再生できる個人利用向けのGitHub Pages版作戦キャンバスです。

作戦データはGitHubへ保存されません。OneDriveへ接続すると、作戦JSON・動画素材・保存フォルダ設定をPC、iPad、iPhoneなどの端末間で共有できます。JSONの保存・読込と一括バックアップにも対応しています。

表示名称はZEROONE CANVASへ変更しましたが、既存データとの互換性を保つため、JSON形式・OneDrive参照・端末内保存キーは従来のまま維持しています。
