# ZEROONE CANVAS｜動くバスケ作戦キャンバス v45

「問いから、プレーをつくる。」をコンセプトに、バスケットボールの作戦を作成・保存・再生できる個人利用向けのGitHub Pages版作戦キャンバスです。

作戦データはGitHubへ保存されません。OneDriveへ接続すると、作戦JSON・動画素材・保存フォルダ設定をPC、iPad、iPhoneなどの端末間で共有できます。JSONの保存・読込と一括バックアップにも対応しています。

表示名称はZEROONE CANVASへ変更しましたが、既存データとの互換性を保つため、JSON形式・OneDrive参照・端末内保存キーは従来のまま維持しています。

v45では、通常表示・全画面表示ともテキストをアプリ内の入力欄で追加・編集します。「決定」で反映し、「キャンセル」で元の内容を保ちます。保存操作中は「保存中…」を表示し、完了または失敗まで保存ボタンを無効にします。

## OneDriveの接続操作

ツールバーの雲アイコンに「未接続」「接続済み」「再接続」などの短い状態表示を付けます。チェック印・注意マーク・文字で状態を区別し、接続済みなら共通の「OneDrive 接続設定」を開きます。未接続なら直接Microsoftへ接続し、アカウント選択を毎回強制しません。アカウント変更とサインアウトは共通ダイアログに統一し、旧接続ボタンは削除しています。

「接続済み」は認証・接続の状態です。保存・同期の完了は各アプリの保存表示で確認してください。Safariの「履歴とWebサイトデータを消去」後は再接続が必要です。既存の保存領域・OneDriveのファイル形式・AppFolder権限を維持しています。
